# Mohsin Ali Asghar — 3D Portfolio

## Files
- index.html — portfolio structure/content
- main.css — visual design/responsive styles
- app.js — Three.js background + interactions
- Mohsin-suit.jpeg — profile image
- Mohsin_Ali_Asghar_Modern_ATS_CV.pdf — CV linked from the hero

## Run locally
Open `index.html` in a modern browser.

The 3D background loads Three.js from jsDelivr, so an internet connection is needed for the 3D scene.

## Deploy
Upload all files to GitHub Pages, Netlify, Vercel, or any normal static hosting service.
Keep the files in the same folder so the image and CV links work.
